# Actors & Characters

ACT 3 AI's character pipeline maintains visual consistency for your actors across every scene,
every shot, throughout your entire production.

## Creating an Actor

Each actor profile includes:
- **Reference images** — Upload photos or generate a reference image
- **Physical description** — Height, build, age, hair, eye color
- **Wardrobe** — Defined costumes per scene or globally
- **Voice** — TTS voice assignment for dialogue

Once defined, ACT 3 AI maintains this character's appearance across all generated shots.

## Lip Sync

For dialogue scenes, ACT 3 AI's lip sync pipeline:
1. Extracts the audio track (from TTS or uploaded audio)
2. Generates video of the character speaking
3. Applies automated lip sync processing

Lip sync works with all supported video generation models.

## Motion Capture

Import `.bvh` or `.fbx` mocap data to drive character animations. ACT 3 AI integrates with
Blender for full 3D character pipeline support.

## Text-to-Speech

Every character can have an assigned voice. ACT 3 AI supports multiple TTS providers:
- ElevenLabs (ultra-realistic)
- OpenAI TTS
- Deepgram
- System voices

Generate character dialogue directly in ACT 3 AI and sync it to your video shots automatically.
