# Custom Actors Tutorial

Learn how to create a consistent character and use them across multiple scenes.

## Creating a Character Profile

1. Go to **Actors** in the left nav
2. Click **New Actor**
3. Fill in the profile:
   - Name
   - Physical description
   - Age
   - Distinctive features (hair color, style, etc.)

## Uploading Reference Images

For best consistency, upload 3-5 reference images:
- Front-facing, neutral expression
- Side profile
- Full body
- In the wardrobe they'll wear

More references = better consistency across shots.

## Using an Actor in a Shot

When defining a shot:
1. Click **Add Character**
2. Select your actor from the list
3. Define their position in frame and action

ACT 3 AI injects character consistency tokens into the generation prompt automatically.

## Dialogue Shots with Lip Sync

For dialogue scenes:
1. Write the line in the **Dialogue** field
2. Select a voice from the **TTS** dropdown
3. Click **Generate Voice** to preview
4. Enable **Lip Sync** before generating video

The generated video will show your character speaking the dialogue with matching lip movement.
