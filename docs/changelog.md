# Changelog

## v1.1.0 — April 2026

### New Features
- **Google Veo 3 integration** — Generate with Google's most advanced video model
- **Wan 2.1 support** — New open-source model option for local rendering
- **Multi-take comparison** — Generate multiple takes and compare side-by-side

### Improvements
- Faster prompt optimization pipeline (2x speed improvement)
- Improved character consistency for long productions
- Better default cinematography suggestions from script analysis

### Bug Fixes
- Fixed lip sync timing drift on clips over 8 seconds
- Fixed actor profile image upload on Safari
- Corrected export metadata for DCP packages
